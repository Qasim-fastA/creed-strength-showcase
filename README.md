# CREED Gym Showcase

Build a modern, premium gym website for a fictional gym called CREED.

Brand

Name: CREED

Theme: Black and red

Personality: Serious, powerful, disciplined, modern

Target audience: People looking for a high-quality gym and serious training environment

Goal

The website should make visitors want to join the gym and contact the business.

Pages

Home

About

Programs

Trainers

Contact

Home page sections

Navbar with CREED logo and navigation links

Hero section with a strong headline, supporting text, and primary CTA: "Start Your Journey"

Why CREED section with 3–4 benefits

Training programs section

Trainers section

Membership CTA section

Footer with contact information and social links

Design

Black background

Red accent color

White and light-gray text

Bold, modern typography

Premium gym photography

Strong visual hierarchy

Clean spacing

Responsive on mobile, tablet, and desktop

Subtle animations only where useful

No excessive gradients or unnecessary effects

Technical requirements

Use React and TypeScript

Use reusable components

Keep the code organized

Use responsive layouts

Make buttons and navigation functional

Use placeholder content where real business information is unavailable

Do not add authentication, databases, dashboards, or unnecessary backend functionality.
This is a marketing website for a gym.
